# Asumsi Teknis

Dokumen ini melacak semua asumsi teknis yang dibuat agen Antigravity selama pengembangan Portify.id.

1. **Stack Versi**: Menggunakan React 18, Vite, dan Tailwind CSS v3.
2. **File Logo**: Asumsi file logo `Portify.id.png`, `logo P.png`, dan `logo+selogan.png` akan dipindahkan ke folder `public/` atau di-import langsung dari `src/assets/`.
